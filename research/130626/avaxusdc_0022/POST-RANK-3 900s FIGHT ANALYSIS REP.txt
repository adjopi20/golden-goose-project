POST-RANK-3 900s FIGHT ANALYSIS REPORT

1. Research Objective

The purpose of this test is to examine whether the order-flow behavior after the 3rd confirmed setup provides additional predictive information for future trade outcome.

The previous Nth-entry research showed that the 3rd confirmed setup is one of the most stable delayed-entry candidates. However, entering directly at the 3rd setup may still be too early or too noisy. Therefore, this next research layer observes what happens after the 3rd confirmed setup before calculating the result.

The tested hypothesis is:

After the 3rd confirmed setup, the next 900 seconds of same-side and opposite-side bubble activity may explain or separate future max_R_before_SL performance.

In simple terms:

If rank 3 appears, should we enter immediately, or should we wait and observe whether the market becomes clean, noisy, dominated by same-side activity, or pressured by opposite-side activity?

2. Dataset and Method

Instrument:
AVAXUSDC

Base data:
Binance aggTrades data.

Master data:
impulse_bubble_master.parquet

Master data usage:
The master file was used only to identify the 3rd confirmed setup in each impulse group and to retrieve the required context, such as directional bias, previous session value levels, bubble thresholds, and stop buffer.

Raw aggTrades usage:
Raw aggTrades were used to reconstruct all qualified bubbles inside the post-rank-3 evidence window and to calculate the delayed-entry result.

Observation unit:
One row = one 3rd confirmed setup observation.

Overlapping observations:
Every 3rd confirmed setup was treated as an independent research observation, even if the evidence or result windows overlapped. This is acceptable for pattern discovery, but the observations should not be interpreted as fully independent trades.

3. Setup Definition

A confirmed setup is a same-side qualified bubble that passed the original 30-second reaction rule.

The original confirmation rule was:

* Bubble must be outside previous session value area.
* Bubble must align with directional bias:

  * Above previous VAH = long bias.
  * Below previous VAL = short bias.
* Bubble must pass the configured quantity percentile / minimum bubble tier.
* Bubble must pass 30-second MFE threshold.
* Bubble must pass 30-second efficiency threshold.

The current post-rank-3 research only uses impulse groups that already have at least three confirmed setups.

4. Post-Rank-3 Evidence Window

For every 3rd confirmed setup:

Evidence start:
3rd setup confirmation timestamp.

Evidence end:
3rd setup confirmation timestamp + 900 seconds.

Entry timestamp:
Evidence end timestamp.

Therefore:

entry_timestamp = rank3_confirmation_timestamp + 900 seconds

The evidence window is not taken only from the master file because the master is bounded by the original impulse group window. Instead, the raw aggTrades data is used to reconstruct all qualified bubbles inside the full post-rank-3 900-second evidence window.

5. Evidence Bubble Reconstruction

Inside the 900-second evidence window, a raw aggTrade is treated as a qualified evidence bubble if:

For long bias:
price > previous VAH

For short bias:
price < previous VAL

and:

qty passes the configured minimum bubble tier threshold.

Aggressive side classification:

is_buyer_maker = False → buy aggression
is_buyer_maker = True → sell aggression

Relation to bias:

For long bias:
buy aggression = same-side
sell aggression = opposite-side

For short bias:
sell aggression = same-side
buy aggression = opposite-side

6. Fight-State Classification

The 900-second evidence window is classified into one of four simple fight states:

1. same_side_only
   This means at least one same-side qualified bubble appeared, and no opposite-side qualified bubble appeared.

2. neither_same_nor_opposite
   This means no qualified same-side or opposite-side bubble appeared during the 900-second evidence window.

3. both_same_and_opposite
   This means both same-side and opposite-side qualified bubbles appeared during the 900-second evidence window.

4. opposite_side_only
   This means at least one opposite-side qualified bubble appeared, and no same-side qualified bubble appeared.

The test intentionally uses these four simple states instead of more complex dominance labels.

7. Quantity Imbalance Formula

In addition to the four fight-state labels, continuous fight diagnostics were calculated.

Formula:

qty_imbalance_900s = (same_side_qty - opposite_side_qty) / (same_side_qty + opposite_side_qty)

opposite_qty_share_900s = opposite_side_qty / (same_side_qty + opposite_side_qty)

Interpretation:

qty_imbalance near +1 means same-side quantity dominated.

qty_imbalance near -1 means opposite-side quantity dominated.

qty_imbalance near 0 means same-side and opposite-side quantities were balanced.

If same_side_qty + opposite_side_qty = 0, then both qty_imbalance_900s and opposite_qty_share_900s are null.

8. Result Calculation

The result was calculated from the delayed entry point.

Entry timestamp:
rank3_confirmation_timestamp + 900 seconds

Entry price:
last raw aggTrade price at or before the entry timestamp.

Result horizon:
3600 seconds after entry timestamp.

Stop buffer:
0.10% from entry price.

For long setups:

stop_price = entry_price × (1 - stop_buffer_pct)

SL is touched when price <= stop_price.

max_R_before_SL is calculated using the highest price reached before the first SL touch.

Formula:

max_R_before_SL = (highest_price_before_SL - entry_price) / risk_per_unit

For short setups:

stop_price = entry_price × (1 + stop_buffer_pct)

SL is touched when price >= stop_price.

max_R_before_SL is calculated using the lowest price reached before the first SL touch.

Formula:

max_R_before_SL = (entry_price - lowest_price_before_SL) / risk_per_unit

Important rule:

Any favorable R must happen before the first SL touch. If the stop loss is touched before favorable expansion, max_R_before_SL is 0.

11. Main Fight-State Finding

The strongest median result came from:

neither_same_nor_opposite

This condition produced:

Median max_R_before_SL = 1.1975R
Hit >= 2R = 38.05%
SL touch rate = 87.42%

This means that after the 3rd confirmed setup, no additional qualified bubble activity during the next 900 seconds was actually the cleanest delayed-entry condition.

This finding is different from the earlier simple same-side/opposite-side test, where same-side-only was the strongest condition.

In this post-rank-3 layer, the best condition is not “more same-side bubble activity.” Instead, the best condition is “no qualified fight after rank 3.”

Possible interpretation:

After the 3rd confirmed setup, the impulse may already be established. If no more large qualified bubbles appear, the market may be continuing cleanly without noisy two-sided auction activity.

both_same_and_opposite

Interpretation:

Most rank-3 setups are followed by both same-side and opposite-side bubble activity. However, this two-sided fight weakens the delayed entry. The market becomes noisy, and the remaining directional edge after waiting 900 seconds becomes weaker.

16. Quantity Imbalance Test

The test also measured whether the continuous quantity imbalance between same-side and opposite-side bubbles had a relationship with max_R_before_SL.

Pearson correlation:
0.0072

-0.0058

Interpretation:

The relationship is effectively zero.

This means:

More same-side quantity does not automatically imply better max_R_before_SL.

More opposite-side quantity does not automatically imply worse max_R_before_SL.

The simple quantity imbalance metric does not provide meaningful linear or monotonic predictive information in this test.

The qualitative state and reaction type appear more useful than raw same/opposite quantity imbalance.

17. Final Conclusion

The hypothesis was partially supported.

The 900-second post-rank-3 evidence layer does separate future trade outcomes, but not in the originally expected way.

The original expectation was that same-side-only activity after rank 3 would be strongest. However, the actual strongest condition was:

neither_same_nor_opposite

This suggests that after the 3rd confirmed setup, the cleanest continuation may happen when no additional qualified bubble fight appears during the next 900 seconds.

The main conclusions are:

1. Blind rank3 + 900s delayed entry is not strong enough.
   Overall median max_R_before_SL after waiting 900 seconds was only 0.9764R.

2. The best 900-second evidence condition is no qualified bubble activity.
   The neither_same_nor_opposite condition produced median max_R_before_SL of 1.1975R.

3. The strongest specific setup is short + no post-rank3 fight.
   This condition produced median max_R_before_SL of 1.4308R and hit >= 2R of 41.04%.

4. Mixed two-sided fight is weak.
   The both_same_and_opposite condition was the most common state but had weak median performance at 0.9444R.

5. Opposite-side contra-move is dangerous.
   Rows with opposite contra-move had lower median result than rows without opposite contra-move.

6. Absorbed opposite-side bubbles are not necessarily bad.
   Absorbed opposite without contra-move had relatively strong median performance.

7. Raw quantity imbalance is not predictive.
   Pearson and Spearman correlation were both approximately zero.

8. Practical Research Interpretation

The post-rank-3 900-second wait should not be used as a blind delay rule.

The better question is not:

Should I always wait 900 seconds after rank 3?

The better question is:

After rank 3, what type of 900-second evidence justifies a delayed entry?

The current answer is:

The cleanest delayed-entry condition is when no further qualified bubble fight appears after rank 3, especially for short setups.

The most dangerous condition is a noisy two-sided fight, especially when opposite-side bubbles produce contra-move.

19. Next Research Step

The next research step should test:

1. Different evidence horizons:

* 300 seconds
* 600 seconds
* 900 seconds
* 1200 seconds

2. Direction-specific rules:

* long rank3 + 900s may not be useful
* short rank3 + 900s no-fight may be useful

3. Contra-move filters:
   Avoid trades where opposite-side bubbles produce 5s directional contra-move.

4. Non-overlap robustness:
   Since overlapping rank-3 observations were allowed in this test, the next robustness check should test whether the finding survives after removing overlapping observations.

5. Combined rule candidate:
   Potential rule:

* Take only rank-3 confirmed setups.
* Wait 900 seconds.
* Enter only if fight_state_900s = neither_same_nor_opposite.
* Prefer short setups.
* Exclude rows with opposite-side contra-move.

* Use raw aggTrades to reconstruct the evidence window.
* Enter after the evidence window.
* Calculate max_R_before_SL over the next 3600 seconds.

4. 300s is not enough for the short no-fight condition.
   The strong short + no-fight result appeared only in the 900-second test.

5. Opposite contra-move remained a consistent warning sign.

6. Quantity imbalance remained non-predictive.

Overall conclusion:

The 300-second test does not provide a strong enough pattern to continue this research branch. It confirms that post-rank-3 order-flow evidence contains some information, but the effect is weak, inconsistent by direction, and not clean enough to be used as a standalone trading rule.
